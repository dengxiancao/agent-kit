# 界面重构（v2）

这个目录放着 webchat 新版界面的设计与原型，`webchat.py` 已经按它实现。

| 文件 | 说明 |
|---|---|
| `prototype.html` | 可点击的高保真原型（纯静态，双击就能看） |
| `方案.html` | 完整技术方案，内嵌渲染图 |
| `前端重构方案.md` | 同一份方案的 Markdown 版 |
| `shots/desktop.png` | 桌面三栏：会话列表 / 对话 / 运行详情 |
| `shots/desktop-dark.png` | 深色模式 |
| `shots/desktop-bottom.png` | 滚动到对话末尾（代码块、页脚） |
| `shots/mobile.png` | 手机端对话 |
| `shots/mobile-drawer.png` | 手机端会话抽屉 |
| `shots/mobile-inspector.png` | 手机端运行详情弹层 |

> 截图是 `webchat.py` 实际运行后截的，不是设计稿。原型里的数据是写死的，
> 真实界面里的会话、工具输出、token 都是实际值。
